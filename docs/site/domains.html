Domains that never muddy each other

folk remembers real friends, fictional characters, authors, and musicians — and prevents those worlds from blurring together. Collections are physically separate directory trees, logically separate domains, and connected only by edges a human meant to draw.

Collections are config, never code

No collection name appears anywhere in folk's source. Adding a domain is one line in ~/.config/folk/collections:

{"personal":   "~/people/personal",
 "characters": "~/notes/fiction/characters",
 "authors":    "~/notes/books/authors",
 "musicians":  "~/notes/music/people"}

This is invariant 7, and it is stronger than a style rule: the architecture depends on new domains (and later, loci) being config changes. Anything that enumerates a collection name in a .py file has taken a wrong turn — journal roots and loci roots are registered the same way, never hardcoded.

Identity across collections

Collections are memberships, not identities. An author who is also a musician gets one canonical person file and a symlink from the second collection — never two files that could drift. Before any adapter mints a new person: slug, it can ask folk lookup "<name>" --json, which checks every collection and answers: exact match (reuse silently), near-matches (never auto-merge — flag for a human), or genuinely new.

Loci: places with personalities

A Locus is a narrative place — a writing room, a Murakami-flavored world — built from two existing mechanics composed, with no new machinery: a person-like markdown file (its ## Genius Loci section holds mood, rules, personality) and a scope tag (locus) carried on journal events. Scenes are just conversations whose events carry the tag — stamped mechanically by the source adapter, never guessed by the promotion LLM, because scoping is a trust decision and trust decisions stay deterministic.

The four locus decisions, compressed

  • Default barrier, explicit wormhole. Locus-scoped views admit only locus-tagged events and curated associations — and a person's own default profile is never widened by guest appearances elsewhere. The barrier is enforced on the Locus side.
  • Locus tags are declared, never inferred. The surface (an agent's profile bound to a Locus, a chat UI's folder) stamps the tag mechanically. A mislabeled locus would be a scoping error, and scoping errors must stay in the deterministic part of the pipeline.
  • Authority splits along the three-records line. The Locus file curates cast and pillar scenes (Bedrock); journal events carry what happened there; the index derives the union at rebuild. Same invariant, same guarantee as people.
  • Locus files live with their domain. Per-collection loci/ subdirectories (or explicit registration in ~/.config/folk/loci-roots) — a Murakami Locus sits next to characters, a life-planning Locus next to personal. Registration requires zero code changes.
